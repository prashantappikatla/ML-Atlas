## Overview

DeepWalk is an unsupervised learning algorithm that generates low-dimensional vector representations (embeddings) of nodes in a graph. It achieves this by adapting the [Word2Vec](/algorithms/deep-learning/self-supervised-learning/word2vec) SkipGram model to learn from sequences of nodes generated by truncated random walks. The algorithm effectively captures both local and global structural information of the graph, making node embeddings useful for various downstream machine learning tasks.

## History

**2014** — Perozzi, Al-Rfou, and Skiena introduced DeepWalk, pioneering the use of truncated random walks and the SkipGram model for unsupervised graph representation learning.

**2016** — [Node2Vec](/algorithms/graph/graph-embeddings/node2vec) was introduced by Grover and Leskovec, extending DeepWalk's random walk strategy by introducing biased random walks to balance breadth-first and depth-first exploration.

**2017** — LINE (Large-scale Information Network Embedding) was proposed by Tang et al., offering an alternative approach to learn embeddings by preserving first-order and second-order proximities.

**2018** — [GraphSAGE](/algorithms/graph/graph-embeddings/graphsage) was introduced by Hamilton et al., providing an inductive framework for generating node embeddings by sampling and aggregating features from a node's local neighborhood, addressing DeepWalk's transductive limitation.

## Mathematical Intuition

### Graph Embeddings Objective

The primary goal of DeepWalk is to learn a latent representation mapping $\Phi: V \to \mathbb{R}^d$ for each node $v \in V$ in a graph $G=(V, E)$, where $d$ is the embedding dimension. This mapping should preserve neighborhood relationships such that nodes that are 'similar' in the graph structure are close in the embedding space. DeepWalk achieves this by maximizing the likelihood of observing a node's neighbors given its embedding, similar to language modeling.

### Random Walks for Node Sequences

DeepWalk generates sequences of nodes by performing truncated random walks on the graph. For each node $v_i \in V$, a random walk $W_{v_i} = (w_0, w_1, \dots, w_k)$ of fixed length $k$ is initiated, where $w_0 = v_i$ and $w_{j+1}$ is chosen uniformly at random from the neighbors of $w_j$. These sequences are analogous to sentences in natural language processing, where nodes are words. The probability of transitioning from node $v_j$ to $v_{j+1}$ is $P(v_{j+1} | v_j) = \frac{1}{|N(v_j)|}$ if $v_{j+1} \in N(v_j)$, and $0$ otherwise, where $N(v_j)$ denotes the set of neighbors of $v_j$.

### SkipGram Model Adaptation

The generated node sequences are then fed into a SkipGram model, originally designed for [Word2Vec](/algorithms/deep-learning/self-supervised-learning/word2vec). The SkipGram model learns node embeddings by predicting the context (neighboring nodes) of a target node within a fixed-size window. Specifically, for each node $v_i$ in a random walk, the model aims to maximize the probability of observing its neighbors $N_s(v_i)$ within a window of size $s$ around $v_i$, given $v_i$'s embedding $\Phi(v_i)$. The objective function for a single random walk is to maximize: $$ \sum_{v_i \in W} \sum_{v_j \in N_s(v_i)} \log P(v_j | \Phi(v_i)) $$ where $P(v_j | \Phi(v_i))$ is typically modeled using a softmax function: $$ P(v_j | \Phi(v_i)) = \frac{\exp(\Phi(v_j) \cdot \Phi(v_i))}{\sum_{v_k \in V} \exp(\Phi(v_k) \cdot \Phi(v_i))} $$ Due to the computational cost of the denominator, negative sampling is often used as an approximation.

P(v_j | \Phi(v_i)) = \frac{\exp(\Phi(v_j) \cdot \Phi(v_i))}{\sum_{v_k \in V} \exp(\Phi(v_k) \cdot \Phi(v_i))}
$$

## Algorithm Steps

1. Initialize node embeddings $\Phi(v)$ for all nodes $v \in V$ randomly, typically from a uniform distribution.
2. For each node $v \in V$ in the graph, generate a fixed number of random walks, each of a specified length $k$.
3. For each generated random walk, extract pairs of (target node, context node) within a sliding window of size $s$.
4. Feed these (target node, context node) pairs into a SkipGram model, which uses a neural network with a single hidden layer.
5. Train the SkipGram model to maximize the probability of observing context nodes given target nodes, typically using stochastic gradient descent and negative sampling to optimize the objective function.
6. After training, the learned weights from the hidden layer (or input layer, depending on implementation) serve as the low-dimensional embeddings $\Phi(v)$ for each node $v$.

## Strengths

- DeepWalk is an unsupervised method, requiring no labeled data for training, which is beneficial for many real-world graphs.
- It is highly scalable to large graphs due to the localized nature of random walks and the efficiency of the SkipGram model.
- The algorithm effectively captures both local and global structural information of the graph through its random walk sampling strategy.
- The learned embeddings are versatile and can be used as features for various downstream machine learning tasks like classification, clustering, and link prediction.
- DeepWalk is relatively simple to implement and understand, building upon established concepts from natural language processing.

## Weaknesses

- DeepWalk is a transductive method, meaning it cannot generate embeddings for new, unseen nodes without retraining the entire model.
- The random walk generation process can be computationally intensive for very dense graphs or when many long walks are required.
- It does not directly incorporate node features or edge attributes, relying solely on the graph's topological structure.
- The performance is sensitive to hyperparameters such as walk length, number of walks per node, embedding dimension, and window size.
- The uniform random walk strategy might not optimally explore all relevant parts of the graph, potentially missing important structural information.

## Use Cases

### Social Networks

Used for node classification (e.g., identifying user communities), link prediction (e.g., suggesting new friendships), and anomaly detection (e.g., finding bot accounts).

### Recommendation Systems

Applied to user-item interaction graphs to learn embeddings for users and items, which can then be used for personalized recommendations.

### Bioinformatics

Utilized in protein-protein interaction networks or gene regulatory networks to identify functional modules or predict protein functions.

### Knowledge Graphs

Employed to embed entities and relations in knowledge graphs, facilitating tasks like knowledge graph completion and entity linking.

### Cybersecurity

Used in network traffic graphs or system call graphs to detect malicious activities or identify compromised machines through anomalous node behavior.
