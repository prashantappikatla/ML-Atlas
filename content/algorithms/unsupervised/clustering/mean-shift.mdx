## Overview

Mean Shift is a non-parametric clustering algorithm that identifies modes (peaks) in the data's density distribution. It works by iteratively shifting data points towards regions of higher density until convergence, effectively grouping points that converge to the same mode into a cluster. This approach allows it to discover arbitrarily shaped clusters without requiring the number of clusters to be specified beforehand, making it particularly useful for tasks like image segmentation and object tracking.

## History

**1975** — Keinosuke Fukunaga and L.D. Hostetler introduced the concept of the mean shift procedure for estimating modes of a probability density function, laying the theoretical groundwork.

**1995** — Yizong Cheng applied the mean shift algorithm to image processing tasks, demonstrating its practical utility for tasks such as image segmentation and filtering.

**2002** — Dorin Comaniciu and Peter Meer published their seminal paper "Mean Shift: A Robust Approach Toward Feature Space Analysis," significantly popularizing the algorithm for computer vision and general clustering applications.

## Mathematical Intuition

### Kernel Density Estimation Foundation

Mean Shift is fundamentally rooted in non-parametric density estimation, specifically Kernel Density Estimation (KDE). Given a set of $n$ data points $x_i \in R^d$, the KDE at a point $x$ with a kernel $K(x)$ and bandwidth $h$ is given by:$$ \hat{f}(x) = \frac{1}{n h^d} \sum_{i=1}^n K\left(\frac{x - x_i}{h}\right) $$The gradient of the density estimate, $\nabla \hat{f}(x)$, points in the direction of the steepest ascent of the density. The mean shift algorithm iteratively moves points in this direction to find local maxima (modes) of the density function.

$$
\hat{f}(x) = \frac{1}{n h^d} \sum_{i=1}^n K\left(\frac{x - x_i}{h}\right)
$$

### Mean Shift Vector Derivation

For a radially symmetric kernel $K(x) = c_k k(\|x\|^2)$, where $c_k$ is a normalization constant, the gradient of the KDE can be expressed as:$$ \nabla \hat{f}(x) = \frac{2 c_k}{n h^{d+2}} \sum_{i=1}^n (x_i - x) k'\left(\left\|\frac{x - x_i}{h}\right\|^2\right) $$If we define $g(s) = -k'(s)$, and assume a Gaussian kernel where $k(s) = e^{-s/2}$, then $g(s) = \frac{1}{2} e^{-s/2}$. The gradient can be rewritten to reveal the mean shift vector:$$ \nabla \hat{f}(x) = \frac{2 c_k}{n h^{d+2}} \left[ \sum_{i=1}^n g\left(\left\|\frac{x - x_i}{h}\right\|^2\right) \right] \left[ \frac{\sum_{i=1}^n x_i g\left(\left\|\frac{x - x_i}{h}\right\|^2\right)}{\sum_{i=1}^n g\left(\left\|\frac{x - x_i}{h}\right\|^2\right)} - x \right] $$The term in the second bracket is the mean shift vector $M_h(x)$, which points from $x$ to the weighted mean of data points within the bandwidth $h$.

$$
\nabla \hat{f}(x) = \frac{2 c_k}{n h^{d+2}} \sum_{i=1}^n (x_i - x) k'\left(\left\|\frac{x - x_i}{h}\right\|^2\right)
$$

$$
M_h(x) = \frac{\sum_{i=1}^n x_i g\left(\left\|\frac{x - x_i}{h}\right\|^2\right)}{\sum_{i=1}^n g\left(\left\|\frac{x - x_i}{h}\right\|^2\right)} - x
$$

### Iterative Mode Seeking

The mean shift algorithm iteratively updates a point $x_t$ by moving it in the direction of the mean shift vector:$$ x_{t+1} = x_t + M_h(x_t) = \frac{\sum_{i=1}^n x_i g\left(\left\|\frac{x_t - x_i}{h}\right\|^2\right)}{\sum_{i=1}^n g\left(\left\|\frac{x_t - x_i}{h}\right\|^2\right)} $$This update rule effectively moves the point $x_t$ to the weighted mean of the data points in its neighborhood, where the weights are determined by the kernel function $g$. Each iteration guarantees movement towards a higher density region, eventually converging to a local maximum of the density function.

$$
x_{t+1} = x_t + M_h(x_t) = \frac{\sum_{i=1}^n x_i g\left(\left\|\frac{x_t - x_i}{h}\right\|^2\right)}{\sum_{i=1}^n g\left(\left\|\frac{x_t - x_i}{h}\right\|^2\right)}
$$

## Algorithm Steps

1. Initialize a set of starting points (seeds), which can be all data points or a subset, often generated by binning.
2. For each starting point $x_j$, define a search window of radius $h$ (bandwidth) around it.
3. Calculate the mean shift vector $M_h(x_j)$ for $x_j$ by computing the weighted mean of all data points $x_i$ within its search window, where weights are determined by a kernel function.
4. Shift the starting point $x_j$ by the mean shift vector: $x_{j, \text{new}} = x_j + M_h(x_j)$.
5. Repeat the calculation and shifting steps for $x_{j, \text{new}}$ until the magnitude of the shift is smaller than a predefined tolerance or a maximum number of iterations is reached, indicating convergence to a mode.
6. Assign all data points that converged to the same mode (within a certain distance threshold) to the same cluster.
7. Optionally, merge modes that are very close to each other to form the final set of clusters.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `bandwidth` | `float or None` | `None` | positive float | Bandwidth parameter for the RBF kernel. If None, it is estimated using `estimate_bandwidth`. |
| `seeds` | `array-like of shape (n_samples, n_features) or None` | `None` |  | Points used as initial centers of the search windows. If None, `bin_seeding` is used to generate seeds. |
| `bin_seeding` | `boolean` | `False` | True, False | If true, initial seeds are generated by binning data points in a grid, which can speed up computation. |
| `min_bin_freq` | `integer` | `1` | positive integer | Minimum number of points in a bin for it to be considered a seed. Only used if `bin_seeding` is True. |
| `cluster_all` | `boolean` | `True` | True, False | If true, all points are assigned to a cluster. If false, points that are not within the bandwidth of any mode are left unassigned. |
| `max_iter` | `integer` | `300` | positive integer | Maximum number of iterations for the mean shift procedure for each seed. |
| `n_jobs` | `integer or None` | `None` | integer, -1, None | The number of jobs to use for the computation. -1 means using all processors. |

## Strengths

- Mean Shift does not require prior knowledge of the number of clusters, as it discovers them based on data density.
- It can identify arbitrarily shaped clusters, unlike algorithms that assume spherical cluster geometries.
- The algorithm is robust to outliers because they typically reside in low-density regions and do not significantly influence the mean shift vector of other points.
- The resulting cluster centroids are actual modes of the data distribution, providing a natural interpretation of cluster centers.
- It is a non-parametric method, making no assumptions about the underlying distribution of the data.

## Weaknesses

- The computational complexity of Mean Shift can be high, especially for large datasets, as it involves neighborhood searches for each point in every iteration.
- The performance of the algorithm is highly sensitive to the choice of the bandwidth parameter, which can be challenging to tune optimally.
- Mean Shift does not scale well to high-dimensional data due to the curse of dimensionality, where density estimates become unreliable.
- It can produce a large number of small clusters if the bandwidth is too small, making interpretation difficult.
- The algorithm's convergence can be slow for certain data distributions or if the initial points are far from density modes.

## Use Cases

### Image Processing

Used for image segmentation, where pixels are grouped into regions based on color and spatial proximity, leading to object recognition and background separation.

### Computer Vision

Applied in object tracking, where the mean shift vector helps locate the most probable position of an object in subsequent frames by tracking density modes.

### Data Analysis

Employed for exploratory data analysis and clustering tasks to identify natural groupings in datasets without specifying the number of clusters.

### Medical Imaging

Utilized for segmenting anatomical structures in MRI or CT scans, aiding in diagnosis and treatment planning.

### Traffic Analysis

Can be used to identify traffic hotspots or congestion patterns by clustering vehicle density data in urban areas.
