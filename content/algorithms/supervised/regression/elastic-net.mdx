## Overview

Elastic Net is a regularized [Linear Regression](/algorithms/supervised/regression/linear-regression) model that combines the penalties of both Lasso (L1 regularization) and Ridge (L2 regularization) methods. This hybrid approach enables it to perform automatic feature selection while simultaneously handling highly correlated predictors. It addresses some limitations of Lasso, such as its tendency to select only one variable from a group of correlated variables and its instability in high-dimensional settings.

## History

**1970** — [Arthur Hoerl](https://en.wikipedia.org/wiki/Ridge_regression) and [Robert Kennard](https://en.wikipedia.org/wiki/Ridge_regression) introduced [Ridge Regression](/algorithms/supervised/regression/ridge-regression) to address multicollinearity in [Linear Regression](/algorithms/supervised/regression/linear-regression) by adding an L2 penalty to the loss function.

**1996** — [Robert Tibshirani](https://en.wikipedia.org/wiki/Robert_Tibshirani) proposed Lasso (Least Absolute Shrinkage and Selection Operator) Regression, which uses an L1 penalty for both regularization and automatic feature selection.

**2005** — [Hui Zou](https://en.wikipedia.org/wiki/Elastic_net_regularization) and [Trevor Hastie](https://en.wikipedia.org/wiki/Trevor_Hastie) introduced Elastic Net, combining L1 and L2 penalties to overcome limitations of Lasso, particularly with highly correlated predictors and when the number of features exceeds the number of samples.

## Mathematical Intuition

### The Elastic Net Objective Function

The Elastic Net model minimizes a penalized residual sum of squares. It combines the squared error loss function with a convex combination of the L1 and L2 penalties. The objective function to be minimized for the coefficient vector $\mathbf{w}$ is given by:
$$ \min_{\mathbf{w}} \left( \frac{1}{2n_{samples}} \sum_{i=1}^{n_{samples}} (y_i - \mathbf{w}^T \mathbf{x}_i)^2 + \alpha \left( (1 - \rho) \frac{1}{2} \|\mathbf{w}\|_2^2 + \rho \|\mathbf{w}\|_1 \right) \right) $$
Here, $n_{samples}$ is the number of observations, $y_i$ is the target value, $\mathbf{x}_i$ is the feature vector for the $i$-th sample, $\mathbf{w}$ is the vector of regression coefficients, $\alpha \ge 0$ is the overall regularization strength, and $\rho \in [0, 1]$ is the mixing parameter between L1 and L2 penalties.

$$
\min_{\mathbf{w}} \left( \frac{1}{2n_{samples}} \sum_{i=1}^{n_{samples}} (y_i - \mathbf{w}^T \mathbf{x}_i)^2 + \alpha \left( (1 - \rho) \frac{1}{2} \|\mathbf{w}\|_2^2 + \rho \|\mathbf{w}\|_1 \right) \right)
$$

### L1 Regularization for Sparsity

The L1 penalty term, $\rho \|\mathbf{w}\|_1 = \rho \sum_{j=1}^p |w_j|$, encourages sparsity in the coefficient vector $\mathbf{w}$. This means it drives some coefficients exactly to zero, effectively performing automatic feature selection. The L1 penalty creates a diamond-shaped constraint region, and the first point of contact with the error contours often occurs at an axis, leading to zero coefficients.

$$
\|\mathbf{w}\|_1 = \sum_{j=1}^p |w_j|
$$

### L2 Regularization for Shrinkage

The L2 penalty term, $(1 - \rho) \frac{1}{2} \|\mathbf{w}\|_2^2 = (1 - \rho) \frac{1}{2} \sum_{j=1}^p w_j^2$, shrinks the coefficients towards zero but typically does not set them exactly to zero. This helps in reducing the variance of the model and is particularly effective in handling multicollinearity by distributing the impact of correlated predictors. The L2 penalty creates a spherical constraint region.

$$
\|\mathbf{w}\|_2^2 = \sum_{j=1}^p w_j^2
$$

### Combining L1 and L2 Penalties

The Elastic Net penalty, $\alpha \left( (1 - \rho) \frac{1}{2} \|\mathbf{w}\|_2^2 + \rho \|\mathbf{w}\|_1 \right)$, combines the benefits of both Lasso and Ridge. When $\rho=1$, it becomes Lasso; when $\rho=0$, it becomes Ridge. For $0 < \rho < 1$, it performs both feature selection and coefficient shrinkage. This combination allows Elastic Net to select groups of correlated variables together, unlike Lasso which tends to pick only one, and to handle cases where the number of predictors $p$ is much larger than the number of samples $n$.

$$
\alpha \left( (1 - \rho) \frac{1}{2} \|\mathbf{w}\|_2^2 + \rho \|\mathbf{w}\|_1 \right)
$$

## Algorithm Steps

1. Standardize the input features $\mathbf{X}$ and the target variable $\mathbf{y}$ to have zero mean and unit variance, if an intercept is to be fitted.
2. Define the Elastic Net objective function, which is the sum of the mean squared error and the combined L1 and L2 penalty terms, controlled by hyperparameters $\alpha$ and $\rho$.
3. Choose appropriate values for the regularization strength $\alpha$ and the L1 ratio $\rho$, often through cross-validation.
4. Initialize the regression coefficients $\mathbf{w}$ (and intercept $w_0$) to small random values or zeros.
5. Iteratively update the coefficients $\mathbf{w}$ by minimizing the objective function using an optimization algorithm such as coordinate descent.
6. During each iteration, for each coefficient $w_j$, update its value while holding all other coefficients constant, using a soft-thresholding operator for the L1 part and shrinkage for the L2 part.
7. Repeat the updates until the coefficients converge, meaning the change in coefficients between iterations falls below a specified tolerance $tol$, or a maximum number of iterations $max\_iter$ is reached.
8. The final converged coefficients $\mathbf{w}$ represent the learned model.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `alpha` | `float` | `1.0` | alpha >= 0 | Constant that multiplies the penalty terms. alpha = 0 is equivalent to Ordinary Least Squares. |
| `l1_ratio` | `float` | `0.5` | 0.0 <= l1_ratio <= 1.0 | The Elastic Net mixing parameter, with $0 \le \text{l1\_ratio} \le 1$. For l1_ratio = 0 the penalty is an L2 penalty. For l1_ratio = 1 it is an L1 penalty. For $0 < \text{l1\_ratio} < 1$, the penalty is a combination of L1 and L2. |
| `fit_intercept` | `bool` | `True` | True, False | Whether to calculate the intercept for this model. If set to False, no intercept will be used in calculations (i.e., data is expected to be already centered). |
| `precompute` | `bool or str` | `'auto'` | True, False, 'auto' | Whether to use a precomputed Gram matrix to speed up calculations. If set to 'auto', the Gram matrix will be precomputed when n_samples > n_features. |
| `max_iter` | `int` | `1000` | max_iter > 0 | The maximum number of iterations to run the coordinate descent algorithm. |
| `tol` | `float` | `0.0001` | tol > 0 | The tolerance for the optimization. If the updates are smaller than tol, the optimization code checks the dual gap for optimality and continues until it is smaller than tol. |
| `selection` | `str` | `'cyclic'` | 'cyclic', 'random' | If 'random', a random coefficient is updated at each iteration rather than looping over features sequentially by default. This can significantly reduce computation time when n_features is large. |
| `random_state` | `int or RandomState instance or None` | `None` | integer, None | Used when selection is set to 'random' to ensure reproducibility. |

## Strengths

- It performs automatic feature selection by driving some coefficients exactly to zero, similar to Lasso.
- It can select groups of correlated features together, which is an advantage over Lasso when dealing with highly correlated predictors.
- It is robust to multicollinearity due to the L2 penalty, which shrinks coefficients of correlated variables proportionally.
- It is effective in high-dimensional settings where the number of features $p$ exceeds the number of samples $n$.
- The L2 penalty helps stabilize the model and reduces variance, making it more robust to noise.
- The model is interpretable as it is a linear model with a sparse set of features.

## Weaknesses

- Tuning the two hyperparameters, $\alpha$ and $\rho$, can be computationally more expensive than tuning a single hyperparameter for Lasso or Ridge.
- It assumes a linear relationship between features and the target variable, which may not hold for complex, non-linear datasets.
- The performance can be sensitive to the scaling of input features, necessitating proper preprocessing like standardization.
- For very high-dimensional data with many irrelevant features, the computational cost of optimization can still be significant.

## Use Cases

### Genomics

Identifying a subset of genes (features) that are most predictive of a disease outcome, even when genes are highly correlated.

### Financial Modeling

Predicting stock prices or credit risk by selecting relevant financial indicators from a large pool of potentially correlated variables.

### Drug Discovery

Pinpointing chemical properties or molecular descriptors that contribute most to a drug's efficacy or toxicity.

### Marketing Analytics

Determining which customer demographics and behaviors are most influential in predicting purchasing decisions or churn, handling correlated marketing campaign data.

### Environmental Science

Modeling air pollution levels based on various meteorological and emission factors, where many factors might be interdependent.
