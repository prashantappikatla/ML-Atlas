## Overview

Lasso Regression, or Least Absolute Shrinkage and Selection Operator, is a [Linear Regression](/algorithms/supervised/regression/linear-regression) method that performs both variable selection and regularization to enhance the prediction accuracy and interpretability of the statistical model. It achieves this by adding an L1 penalty to the ordinary least squares objective function, which encourages sparsity in the model coefficients. This sparsity means that some coefficients are driven exactly to zero, effectively performing automatic feature selection.

## History

**1996** — [Robert Tibshirani](https://en.wikipedia.org/wiki/Robert_Tibshirani) introduced the Lasso method in his paper "Regression Shrinkage and Selection via the Lasso," demonstrating its ability to perform both shrinkage and variable selection.

**1998** — [Bradley Efron](https://en.wikipedia.org/wiki/Bradley_Efron) and [Trevor Hastie](https://en.wikipedia.org/wiki/Trevor_Hastie) further explored the properties of Lasso and its relationship to other shrinkage methods like [Ridge Regression](/algorithms/supervised/regression/ridge-regression).

**2004** — The [Elastic Net](/algorithms/supervised/regression/elastic-net) regularization, combining L1 and L2 penalties, was introduced by Zou and Hastie, addressing some limitations of Lasso, particularly with highly correlated predictors.

**2007** — Friedman, Hastie, and Tibshirani developed efficient algorithms for fitting generalized linear models with L1 penalties, including coordinate descent, making Lasso more practical for large datasets.

## Mathematical Intuition

### Ordinary Least Squares (OLS) Objective

The fundamental goal of [Linear Regression](/algorithms/supervised/regression/linear-regression) is to find a linear relationship between input features $X$ and a target variable $y$. The OLS objective minimizes the sum of squared residuals:
$$ \min_{\beta} \sum_{i=1}^{n} (y_i - \beta_0 - \sum_{j=1}^{p} x_{ij}\beta_j)^2 $$
where $n$ is the number of samples, $p$ is the number of features, $y_i$ is the target for sample $i$, $x_{ij}$ is the $j$-th feature for sample $i$, and $\beta_j$ are the regression coefficients.

$$
\min_{\beta} \sum_{i=1}^{n} (y_i - \beta_0 - \sum_{j=1}^{p} x_{ij}\beta_j)^2
$$

### Lasso Regression Objective Function

Lasso Regression modifies the OLS objective by adding an L1 penalty term to the sum of squared residuals. This penalty is proportional to the sum of the absolute values of the coefficients.
$$ \min_{\beta} \left( \frac{1}{2n} \sum_{i=1}^{n} (y_i - \beta_0 - \sum_{j=1}^{p} x_{ij}\beta_j)^2 + \alpha \sum_{j=1}^{p} |\beta_j| \right) $$
Here, $\alpha \ge 0$ is the regularization parameter, controlling the strength of the L1 penalty. A larger $\alpha$ leads to more coefficients being shrunk towards zero, increasing sparsity.

$$
\min_{\beta} \left( \frac{1}{2n} \sum_{i=1}^{n} (y_i - \beta_0 - \sum_{j=1}^{p} x_{ij}\beta_j)^2 + \alpha \sum_{j=1}^{p} |\beta_j| \right)
$$

$$
\alpha \ge 0
$$

### Sparsity from L1 Penalty

The L1 penalty, $\sum_{j=1}^{p} |\beta_j|$, has a unique property that encourages coefficients to become exactly zero. Geometrically, the constraint region for the L1 penalty (for a fixed sum of absolute coefficients) forms a diamond shape in 2D (an octahedron in higher dimensions). When the elliptical contours of the squared error function touch the corners of this diamond, the optimal solution often lies on an axis, forcing the corresponding coefficient to zero. In contrast, the L2 penalty ([Ridge Regression](/algorithms/supervised/regression/ridge-regression)) has a circular constraint region, leading to coefficients being shrunk towards zero but rarely exactly to zero.

$$
\sum_{j=1}^{p} |\beta_j|
$$

### Optimization via Coordinate Descent

Due to the non-differentiability of the absolute value function at zero, standard gradient descent cannot be directly applied. Instead, algorithms like coordinate descent are commonly used. Coordinate descent optimizes the objective function with respect to one coefficient $\beta_j$ at a time, holding all other coefficients fixed. For Lasso, the update rule for $\beta_j$ involves a soft-thresholding operator:
$$ \hat{\beta}_j = \frac{S(\sum_{i=1}^{n} x_{ij}(y_i - \sum_{k \ne j} x_{ik}\beta_k), n\alpha)}{\sum_{i=1}^{n} x_{ij}^2} $$
where $S(z, \gamma) = \text{sgn}(z) \max(0, |z| - \gamma)$ is the soft-thresholding operator. This process is iterated until convergence.

$$
\hat{\beta}_j = \frac{S(\sum_{i=1}^{n} x_{ij}(y_i - \sum_{k \ne j} x_{ik}\beta_k), n\alpha)}{\sum_{i=1}^{n} x_{ij}^2}
$$

$$
S(z, \gamma) = \text{sgn}(z) \max(0, |z| - \gamma)
$$

## Algorithm Steps

1. Standardize the input features $X$ and center the target variable $y$ to have zero mean.
2. Initialize the regression coefficients $\beta_j$ (e.g., to zero) and the intercept $\beta_0$.
3. For a given regularization parameter $\alpha$, iterate through each coefficient $\beta_j$ (for $j=1, \dots, p$).
4. Compute the partial residual for $\beta_j$ by subtracting the contributions of all other coefficients from the target variable: $y_i^* = y_i - \sum_{k \ne j} x_{ik}\beta_k$.
5. Update $\beta_j$ using the soft-thresholding operator: $\hat{\beta}_j = \frac{S(\sum_{i=1}^{n} x_{ij}y_i^*, n\alpha)}{\sum_{i=1}^{n} x_{ij}^2}$.
6. Repeat steps 3-5 for all coefficients until the changes in coefficients fall below a specified tolerance or a maximum number of iterations is reached.
7. If the data was standardized, transform the coefficients back to the original scale.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `alpha` | `float` | `1.0` | alpha >= 0 | The constant that multiplies the L1 term. alpha = 0 is equivalent to Ordinary Least Squares. |
| `fit_intercept` | `boolean` | `True` | True, False | Whether to calculate the intercept for this model. If set to false, no intercept will be used in calculations (i.e. data is expected to be centered). |
| `precompute` | `boolean or array-like` | `False` | True, False, 'auto' | Whether to use a precomputed Gram matrix to speed up calculations. |
| `max_iter` | `integer` | `1000` | max_iter > 0 | The maximum number of iterations to perform. |
| `tol` | `float` | `1e-4` | tol > 0 | The tolerance for the optimization: if the updates are smaller than tol, the optimization code checks the dual gap for optimality and continues until it is smaller than tol. |
| `selection` | `string` | `cyclic` | 'cyclic', 'random' | If set to 'random', a random coefficient is updated at each iteration rather than cycling over features one by one. |

## Strengths

- Lasso performs automatic feature selection by driving less important feature coefficients exactly to zero, leading to sparser and more interpretable models.
- It can handle datasets with a large number of features, making it suitable for high-dimensional data where many features might be irrelevant.
- The L1 regularization helps prevent overfitting by shrinking coefficients, improving the model's generalization performance on unseen data.
- Lasso models are often more interpretable than other complex models due to their inherent sparsity, making it easier to understand which features are most influential.
- It is computationally efficient, especially with modern algorithms like coordinate descent, allowing it to scale to moderately large datasets.

## Weaknesses

- When there is a group of highly correlated features, Lasso tends to arbitrarily select only one feature from the group and set the others to zero, which can be unstable across different datasets.
- Lasso can struggle when the number of features $p$ is much larger than the number of samples $n$, as it can select at most $n$ features.
- The choice of the regularization parameter $\alpha$ is crucial, and an inappropriate value can lead to underfitting (too much shrinkage) or overfitting (too little shrinkage).
- Lasso's performance can be suboptimal if the true underlying model is not sparse or if all features are genuinely important.
- The L1 penalty can lead to biased coefficient estimates for the selected features, as it shrinks them towards zero.

## Use Cases

### Genomics

Identifying a small subset of genes that are most predictive of a disease outcome from a vast number of genetic markers.

### Finance

Building predictive models for stock prices or credit risk, where feature selection helps identify key economic indicators.

### Econometrics

Selecting relevant economic variables to model inflation, GDP growth, or unemployment rates, improving model interpretability.

### Signal Processing

Denoising signals or reconstructing sparse signals from incomplete measurements, leveraging the sparsity-inducing property.

### Marketing

Determining which customer demographics or behavioral features are most influential in predicting purchasing behavior.

### Drug Discovery

Identifying molecular features or chemical properties that are most strongly associated with a drug's efficacy or toxicity.

```python
from sklearn.linear_model import Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

model = Lasso()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"MSE: {mean_squared_error(y_test, y_pred):.4f}")
print(f"R²:  {r2_score(y_test, y_pred):.4f}")
```
