## Algorithm Steps

1. Draw $B$ bootstrap samples from the training data
2. For each bootstrap sample, grow a decision tree:
   - At each node, randomly select $m$ features (typically $m = \sqrt{p}$)
   - Choose the best split among those $m$ features
   - Grow tree to full depth (no pruning)
3. For a new sample, predict with all $B$ trees and take majority vote

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `n_estimators` | int | `100` | Number of trees in the forest |
| `max_features` | str/int | `'sqrt'` | Features to consider at each split |
| `max_depth` | int | `None` | Maximum tree depth (None = full depth) |
| `min_samples_split` | int | `2` | Min samples to split an internal node |
| `min_samples_leaf` | int | `1` | Min samples in a leaf node |
| `random_state` | int | `None` | Random seed |

## Strengths

- Robust to overfitting due to ensemble averaging
- Handles high-dimensional data well
- Provides feature importance scores
- No feature scaling required
- Works well out of the box with minimal tuning

## Weaknesses

- Less interpretable than a single decision tree
- Memory-intensive for large forests
- Slower prediction than linear models
- Can struggle with very high-cardinality categorical features

### Using scikit-learn

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

model = RandomForestClassifier(
    n_estimators=100,
    max_features='sqrt',
    random_state=42,
)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
print("Feature importances:", model.feature_importances_)
```
