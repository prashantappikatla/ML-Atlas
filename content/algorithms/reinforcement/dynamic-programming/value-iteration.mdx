## Overview

Value Iteration is a dynamic programming algorithm designed to compute the optimal policy for a finite [Markov Decision Process](https://en.wikipedia.org/wiki/Markov_decision_process) (MDP). It iteratively updates the value function for each state until it converges to the optimal state-value function, which represents the maximum expected return achievable from any state. From this converged optimal value function, the optimal policy, dictating the best action to take in each state, can be directly derived. This model-based approach guarantees finding the optimal policy for a given MDP model.

## History

**1953** — Richard Bellman introduces the concept of dynamic programming, a method for solving complex problems by breaking them down into simpler subproblems.

**1957** — Richard Bellman publishes his seminal work 'Dynamic Programming,' formalizing the Bellman equations and the principle of optimality, which are foundational to Value Iteration and other reinforcement learning algorithms.

**1962** — Bellman and Kalaba further elaborate on the theory and applications of dynamic programming in their book 'Dynamic Programming and Modern Control Theory'.

**1980** — The resurgence of interest in reinforcement learning solidifies Value Iteration's role as a fundamental algorithm for solving model-based control problems in artificial intelligence.

## Mathematical Intuition

### Optimal Value Function Definition

The objective of Value Iteration is to find the optimal state-value function $V^*(s)$, which represents the maximum expected cumulative discounted reward an agent can obtain starting from state $s$ and acting optimally thereafter. This function satisfies the Bellman Optimality Equation for state-values:

$$
V^*(s) = \max_a \sum_{s', r} p(s', r | s, a) [r + \gamma V^*(s')]
$$

### Iterative Value Function Update

Value Iteration begins with an arbitrary initial value function $V_0(s)$ for all states $s$. It then iteratively refines this function using the Bellman optimality operator. In each iteration $k+1$, the value of a state $s$ is updated based on the maximum expected return from taking any action $a$ in state $s$, considering the current value estimates $V_k(s')$ of successor states $s'$.

$$
V_{k+1}(s) = \max_a \sum_{s', r} p(s', r | s, a) [r + \gamma V_k(s')]
$$

### Convergence Guarantee

The Bellman optimality operator is a contraction mapping for a discount factor $\gamma \in [0, 1)$. This property guarantees that the sequence of value functions $V_0, V_1, V_2, \dots$ generated by the iterative updates will converge to the unique optimal value function $V^*$. The iteration typically stops when the maximum absolute difference between the value functions of successive iterations falls below a predefined small threshold $\theta$.

$$
\max_s |V_{k+1}(s) - V_k(s)| < \theta
$$

### Optimal Policy Extraction

Once the value function has converged to $V^*(s)$, the optimal policy $\pi^*(s)$ can be directly extracted. For each state $s$, the optimal policy dictates choosing the action $a$ that maximizes the expected return, given the optimal values of the successor states. This is a greedy policy with respect to $V^*(s)$.

$$
\pi^*(s) = \arg\max_a \sum_{s', r} p(s', r | s, a) [r + \gamma V^*(s')]
$$

## Algorithm Steps

1. Initialize a value function $V(s)$ for all states $s \in S$ to arbitrary values (e.g., zeros), and set a small convergence threshold $\theta > 0$, a discount factor $\gamma \in [0, 1)$, and a maximum number of iterations.
2. Repeat for a predefined maximum number of iterations or until convergence:
3. Initialize $\Delta = 0$, which will track the maximum change in the value function during the current iteration.
4. For each state $s \in S$ in the environment:
5. Store the current value of state $s$ as $v = V(s)$.
6. Compute the new value for state $s$ by applying the Bellman optimality update: $V(s) = \max_a \sum_{s', r} p(s', r | s, a) [r + \gamma V(s')]$.
7. Update $\Delta = \max(\Delta, |v - V(s)|)$, recording the largest change observed for any state.
8. If $\Delta < \theta$, then the value function has converged; break the iteration loop.
9. Once $V(s)$ has converged to $V^*(s)$, extract the optimal policy $\pi^*(s)$ for each state $s$ by choosing the action $a$ that maximizes the expected return: $\pi^*(s) = \arg\max_a \sum_{s', r} p(s', r | s, a) [r + \gamma V^*(s')]$.
10. Return the optimal policy $\pi^*(s)$.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `gamma` | `float` | `0.99` | [0, 1) | The discount factor, a value between 0 and 1 that determines the importance of future rewards relative to immediate rewards. |
| `theta` | `float` | `1e-6` | > 0 | The convergence threshold; iterations stop when the maximum absolute change in the value function across all states is less than this value. |
| `max_iterations` | `int` | `1000` | > 0 | The maximum number of iterations to perform. The algorithm will stop after this many iterations even if the convergence threshold is not met. |

## Strengths

- Value Iteration is guaranteed to converge to the optimal policy for finite Markov Decision Processes with a discount factor less than one.
- It provides a direct and conceptually clear method for finding the optimal value function and subsequently the optimal policy.
- The algorithm can effectively handle stochastic environments where transitions and rewards are probabilistic.
- It does not require interaction with the environment during the iteration phase, only a complete model of its dynamics.
- The method is relatively simple to understand and implement for problems with small state and action spaces.

## Weaknesses

- Value Iteration requires a complete and accurate model of the environment, including all transition probabilities and reward functions.
- It suffers from the 'curse of dimensionality,' becoming computationally intractable as the number of states or actions grows large.
- The algorithm cannot directly handle continuous state or action spaces without prior discretization, which can lead to loss of information or increased complexity.
- Each iteration involves a full sweep over all states and actions, making it computationally expensive for large state-action spaces.
- The convergence rate can be slow if the discount factor is close to one or if the state space is very large.

## Use Cases

### Robotics

Used for optimal path planning and control in discrete, known environments, enabling robots to navigate and perform tasks efficiently.

### Inventory Management

Applied to determine optimal ordering and stocking policies to minimize costs and meet demand over time in a dynamic system.

### Resource Allocation

Optimizing the allocation of limited resources in systems with well-defined states and transitions, such as network routing or energy management.

### Game Theory

Solving simple matrix games or finding optimal strategies in finite, deterministic games where the opponent's actions are known or can be modeled.

### Financial Portfolio Optimization

Making sequential investment decisions in simplified, discrete market models to maximize long-term returns under various market conditions.
