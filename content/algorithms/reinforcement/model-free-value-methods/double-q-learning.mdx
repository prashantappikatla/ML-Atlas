## Overview

Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) addresses the overestimation bias inherent in standard [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning), which arises from using the same Q-function to select and evaluate actions. It mitigates this issue by employing two independent Q-functions, $Q_A$ and $Q_B$, to decouple the action selection from the action evaluation step. This approach leads to more accurate value estimates and often results in more stable and improved policy learning.

## History

**1989** — Chris Watkins introduced [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning), a model-free reinforcement learning algorithm, in his PhD thesis, laying the foundation for value-based methods.

**2010** — Hado van Hasselt proposed Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) in "Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning)," introducing the idea of using two Q-functions to reduce overestimation bias in value estimates.

**2013** — Deep Q-Networks (DQN) by Mnih et al. combined [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) with deep neural networks and experience replay, enabling it to learn directly from high-dimensional sensory input like images.

**2015** — Hado van Hasselt, Arthur Guez, and David Silver published "Deep Reinforcement Learning with Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning)," extending the Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) principle to Deep Q-Networks (DDQN), significantly improving their performance.

**2018** — Twin Delayed Deep Deterministic Policy Gradients (TD3) by Fujimoto et al. further built upon the idea of using multiple Q-functions to combat overestimation in [Actor-Critic](/algorithms/reinforcement/policy-gradient/actor-critic) methods, demonstrating its broader applicability.

## Mathematical Intuition

### Standard Q-learning Overestimation

Standard [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) updates the Q-value for a state-action pair $(s, a)$ using the Bellman optimality equation:
$$Q(s, a) \leftarrow Q(s, a) + \alpha [R_{t+1} + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$
The $\max_{a'} Q(s', a')$ term uses the same Q-function to both select the action $a'$ that maximizes the future reward and to evaluate its value. When the Q-values are noisy or approximate, this maximization step tends to select actions whose values are overestimated, leading to a systematic positive bias in the Q-value estimates.

$$
Q(s, a) \leftarrow Q(s, a) + \alpha [R_{t+1} + \gamma \max_{a'} Q(s', a') - Q(s, a)]
$$

### Decoupling Selection and Evaluation

Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning) addresses this overestimation by using two separate Q-functions, $Q_A$ and $Q_B$. One Q-function is used to select the action, and the other is used to evaluate its value. For example, to update $Q_A$, the target value is constructed as:
$$Y_t = R_{t+1} + \gamma Q_B(s', \arg\max_{a'} Q_A(s', a'))$$
Here, $Q_A$ selects the greedy action $a'$ in the next state $s'$, but $Q_B$ evaluates the value of that selected action. This decoupling helps to reduce the overestimation bias because the error in one Q-function's estimate is less likely to be correlated with the error in the other's selection.

$$
Y_t = R_{t+1} + \gamma Q_B(s', \arg\max_{a'} Q_A(s', a'))
$$

### Double Q-learning Update Rule

In Double [Q-Learning](/algorithms/reinforcement/model-free-value-methods/q-learning), at each step, one of the two Q-functions (say $Q_A$) is updated, while the other ($Q_B$) is used to form the target. The roles are typically swapped or chosen randomly. The update for $Q_A$ (assuming $Q_B$ is the target evaluator) is:
$$Q_A(s, a) \leftarrow Q_A(s, a) + \alpha [R_{t+1} + \gamma Q_B(s', \arg\max_{a'} Q_A(s', a')) - Q_A(s, a)]$$
Symmetrically, if $Q_B$ were updated, $Q_A$ would be used for evaluation:
$$Q_B(s, a) \leftarrow Q_B(s, a) + \alpha [R_{t+1} + \gamma Q_A(s', \arg\max_{a'} Q_B(s', a')) - Q_B(s, a)]$$
This ensures that the action selection and value evaluation are performed by different, independently learned Q-functions, thereby mitigating the overestimation bias.

$$
Q_A(s, a) \leftarrow Q_A(s, a) + \alpha [R_{t+1} + \gamma Q_B(s', \arg\max_{a'} Q_A(s', a')) - Q_A(s, a)]
$$

$$
Q_B(s, a) \leftarrow Q_B(s, a) + \alpha [R_{t+1} + \gamma Q_A(s', \arg\max_{a'} Q_B(s', a')) - Q_B(s, a)]
$$

## Algorithm Steps

1. Initialize two Q-value functions, $Q_1(s, a)$ and $Q_2(s, a)$, arbitrarily for all state-action pairs, or with small random values.
2. For each episode, initialize the starting state $s$.
3. Repeat for each step of the episode:
4.   a. Select an action $a$ from state $s$ using an $\epsilon$-greedy policy based on the sum of the two Q-functions, $Q_1(s, a) + Q_2(s, a)$.
5.   b. Execute action $a$, observe reward $R$, and the next state $s'$.
6.   c. Randomly choose one of the Q-functions to update, say $Q_1$.
7.   d. Calculate the target value: $Y = R + \gamma Q_2(s', \arg\max_{a'} Q_1(s', a'))$.
8.   e. Update $Q_1(s, a)$ using the learning rate $\alpha$: $Q_1(s, a) \leftarrow Q_1(s, a) + \alpha [Y - Q_1(s, a)]$.
9.   f. Set $s \leftarrow s'$.
10. Repeat until the episode terminates or a maximum number of steps is reached.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `alpha` | `float` | `0.1` | (0.0, 1.0] | The learning rate, controlling the step size at each update. |
| `gamma` | `float` | `0.99` | [0.0, 1.0) | The discount factor, determining the importance of future rewards. |
| `epsilon` | `float` | `0.1` | [0.0, 1.0] | The exploration rate for the $\epsilon$-greedy policy, balancing exploration and exploitation. |
| `n_states` | `int` | `None` | integer > 0 | The number of possible states in the environment, required for tabular Q-functions. |
| `n_actions` | `int` | `None` | integer > 0 | The number of possible actions an agent can take in the environment. |
| `initial_q_value` | `float` | `0.0` | any float | The initial value for all Q-state-action pairs. |

## Strengths

- Significantly reduces the overestimation bias inherent in standard Q-learning, leading to more accurate value estimates.
- Achieves more stable learning and often converges to better policies compared to single Q-learning.
- The method is conceptually simple and requires only a modest increase in computational resources compared to standard Q-learning.
- It can be seamlessly integrated with deep learning architectures, as demonstrated by Deep Double Q-Networks (DDQN).
- Improved sample efficiency can be observed in environments where overestimation bias is a significant problem.

## Weaknesses

- Requires maintaining and updating two separate Q-functions, which doubles the memory footprint and computational cost for Q-value updates.
- While reducing overestimation, it does not entirely eliminate all forms of bias or address other challenges like exploration-exploitation trade-offs.
- Convergence can still be slow in environments with large state-action spaces, especially without function approximation.
- The performance can still be sensitive to hyperparameter tuning, such as the learning rate and discount factor.
