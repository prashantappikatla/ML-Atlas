## Overview

Recurrent [Neural Networks](https://en.wikipedia.org/wiki/Neural_network_(machine_learning))) (RNNs) are a class of artificial neural networks designed to recognize patterns in sequences of data, such as text, speech, or time series. Unlike traditional feedforward networks, RNNs possess an internal memory that allows them to process inputs in a sequential manner, where the output at each step depends on both the current input and the previous computations. This recurrent connection enables them to model temporal dependencies and context within the data.

## History

**1986** — [David Rumelhart](https://en.wikipedia.org/wiki/David_Rumelhart), [Geoffrey Hinton](https://en.wikipedia.org/wiki/Geoffrey_Hinton), and Ronald Williams introduced Backpropagation Through Time (BPTT) as a method for training recurrent networks, though the concept of recurrent connections existed earlier.

**1990** — Jeffrey Elman published 'Finding Structure in Time', demonstrating the ability of simple recurrent networks (Elman Networks) to learn and predict sequences, significantly popularizing the architecture.

**1997** — [Sepp Hochreiter](https://en.wikipedia.org/wiki/Sepp_Hochreiter) and Jürgen Schmidhuber introduced Long Short-Term Memory ([LSTM](/algorithms/deep-learning/lstm)) networks to address the vanishing gradient problem inherent in traditional RNNs, enabling them to learn long-range dependencies.

**2014** — Kyunghyun Cho et al. introduced Gated Recurrent Units (GRUs), a simplified variant of LSTMs that also mitigate the vanishing gradient problem with fewer parameters.

## Mathematical Intuition

### Core Recurrence Relation

The fundamental operation of a [Recurrent Neural Network](/algorithms/deep-learning/recurrent-neural-network) involves a hidden state $h_t$ that is updated at each time step $t$. This hidden state captures information from the current input $x_t$ and the previous hidden state $h_{t-1}$. The output $y_t$ at time $t$ is typically derived from the current hidden state. The recurrence relation for a simple RNN is defined as follows:

$$
h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t + b_h)
$$

$$
y_t = W_{hy}h_t + b_y
$$

### Backpropagation Through Time

Training RNNs involves extending the backpropagation algorithm to account for the recurrent connections, a method known as Backpropagation Through Time (BPTT). BPTT unrolls the network over time, treating each time step as a separate layer in a deep feedforward network. Gradients are then computed by summing the contributions from each time step. For a loss function $L$ at time $T$, the gradient with respect to a weight matrix $W$ is given by:

$$
\frac{\partial L}{\partial W} = \sum_{t=1}^{T} \frac{\partial L_t}{\partial W}
$$

### Vanishing and Exploding Gradients

A significant challenge in training traditional RNNs is the vanishing and exploding gradient problem. During BPTT, gradients are multiplied repeatedly across many time steps. If the eigenvalues of the recurrent weight matrix $W_{hh}$ are consistently small, gradients can vanish exponentially, making it difficult to learn long-range dependencies. Conversely, if they are consistently large, gradients can explode, leading to unstable training. This issue is often mitigated by architectures like LSTMs and GRUs or techniques like gradient clipping.

## Algorithm Steps

1. Initialize the network's weights and biases, and set the initial hidden state $h_0$ (often to a zero vector).
2. For each time step $t$ in the input sequence, compute the current hidden state $h_t$ using the current input $x_t$ and the previous hidden state $h_{t-1}$.
3. Calculate the output $y_t$ at time $t$ based on the current hidden state $h_t$.
4. Compute the loss $L_t$ at time $t$ by comparing the predicted output $y_t$ with the true target $z_t$.
5. Sum the losses over all time steps to get the total loss $L = \sum_{t=1}^{T} L_t$.
6. Perform Backpropagation Through Time (BPTT) to compute the gradients of the total loss with respect to all network parameters (weights and biases).
7. Update the network parameters using an optimization algorithm (e.g., [Stochastic Gradient Descent](/algorithms/meta-learning/stochastic-gradient-descent), [Adam](/algorithms/meta-learning/adam)) and the calculated gradients.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `hidden_size` | `int` | `128` | positive integer | The number of features in the hidden state $h_t$. This determines the capacity of the RNN to store information. |
| `num_layers` | `int` | `1` | positive integer | The number of recurrent layers stacked on top of each other. Increasing layers can capture more complex patterns. |
| `activation` | `str` | `tanh` | 'tanh', 'relu', 'sigmoid' | The non-linear activation function used in the recurrent layer (e.g., 'tanh', 'relu'). |
| `dropout_rate` | `float` | `0.0` | 0.0 to 1.0 | The probability of an element being zeroed in the output of a layer during training, used to prevent overfitting. |
| `bidirectional` | `bool` | `false` | true, false | If true, the RNN processes the sequence in both forward and backward directions, concatenating their outputs. |
| `learning_rate` | `float` | `0.001` | positive float | The step size at each iteration while moving toward a minimum of the loss function. |

## Strengths

- RNNs are inherently designed to process sequential data of arbitrary length, making them suitable for tasks where order matters.
- They can capture temporal dependencies and context within sequences, allowing for predictions based on past information.
- The parameter sharing across time steps reduces the total number of parameters compared to a feedforward network processing sequences, making them more efficient.
- RNNs can be used in various architectures, including many-to-one (classification), many-to-many (translation), and one-to-many (generation) sequence tasks.

## Weaknesses

- Traditional RNNs suffer from the vanishing and exploding gradient problems, which makes learning long-range dependencies challenging.
- Training RNNs can be computationally expensive and slow, especially for very long sequences, due to the sequential nature of computations.
- They struggle with parallelization during training because the computation at each time step depends on the previous one.
- The simple recurrent structure can have difficulty remembering information over very long sequences without specialized gating mechanisms.

## Use Cases

### Natural Language Processing

Used for tasks like language modeling, machine translation, sentiment analysis, and named entity recognition, where the order of words is crucial.

### Speech Recognition

Applied to convert spoken language into text by processing audio sequences and identifying phonemes or words over time.

### Time Series Forecasting

Utilized for predicting future values in financial markets, weather forecasting, or sensor data by learning patterns from historical time-ordered data.

### Music Generation

Employed to generate new musical sequences by learning patterns and structures from existing musical compositions.

### Video Analysis

Used for activity recognition or video captioning by processing frames of a video as a sequence to understand temporal dynamics.
