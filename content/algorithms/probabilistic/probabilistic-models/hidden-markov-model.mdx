## Overview

Hidden Markov Models (HMMs) are probabilistic graphical models designed to model systems where the observed data is a sequence of emissions generated by an underlying, unobserved (hidden) sequence of states. They provide a statistical framework for analyzing sequential data, making assumptions about the Markovian nature of state transitions and the conditional independence of observations given the current state. HMMs are particularly effective for tasks involving pattern recognition, sequence labeling, and time series analysis where the true generative process is latent.

## History

**1960** — Leonard E. Baum and his colleagues at the Institute for Defense Analyses introduced the foundational theory of Hidden Markov Models, laying the groundwork for their application in signal processing.

**1966** — Baum and T. Petrie published "Statistical Inference for Probabilistic Functions of Finite State Markov Chains," detailing the expectation-maximization algorithm (later known as Baum-Welch) for HMM parameter estimation.

**1967** — Andrew J. Viterbi developed the Viterbi algorithm, an efficient dynamic programming approach for finding the most likely sequence of hidden states given a sequence of observations.

**1970** — HMMs gained significant traction in speech recognition, with researchers like James Baker and Lawrence Rabiner making key contributions to their practical implementation and widespread adoption throughout the 1970s and 1980s.

**1989** — Lawrence Rabiner published "A Tutorial on Hidden Markov Models and Selected Applications in Speech Recognition," which became a seminal reference for the field, popularizing HMMs across various disciplines.

## Mathematical Intuition

### HMM Definition and Components

A Hidden Markov Model is formally defined by a tuple $\lambda = (A, B, \pi)$, where:
- $S = \{s_1, s_2, ..., s_N\}$ is the set of $N$ hidden states.
- $V = \{v_1, v_2, ..., v_M\}$ is the set of $M$ possible observation symbols.
- $A = \{a_{ij}\}$ is the state transition probability distribution, where $a_{ij} = P(q_{t+1} = s_j | q_t = s_i)$ represents the probability of transitioning from state $s_i$ to state $s_j$.
- $B = \{b_j(k)\}$ is the observation likelihood distribution, where $b_j(k) = P(o_t = v_k | q_t = s_j)$ represents the probability of observing symbol $v_k$ when in state $s_j$.
- $\pi = \{\pi_i\}$ is the initial state distribution, where $\pi_i = P(q_1 = s_i)$ is the probability of being in state $s_i$ at time $t=1$.

### Three Fundamental HMM Problems

There are three core problems associated with HMMs:
1.  **Evaluation Problem**: Given an HMM $\lambda$ and an observation sequence $O = (o_1, o_2, ..., o_T)$, compute the probability $P(O | \lambda)$. This is efficiently solved using the Forward Algorithm.
2.  **Decoding Problem**: Given an HMM $\lambda$ and an observation sequence $O$, find the most likely sequence of hidden states $Q = (q_1, q_2, ..., q_T)$ that generated $O$. This is solved using the Viterbi Algorithm.
3.  **Learning Problem**: Given an observation sequence $O$ (and optionally the number of states $N$), estimate the HMM parameters $\lambda = (A, B, \pi)$ that maximize $P(O | \lambda)$. This is solved using the Baum-Welch Algorithm, an instance of the Expectation-Maximization (EM) algorithm.

$$

### Forward Algorithm for Evaluation

The Forward algorithm computes the probability of observing the partial sequence $O_t = (o_1, ..., o_t)$ and being in state $s_i$ at time $t$, denoted as $\alpha_t(i)$.

Initialization:
$$\alpha_1(i) = \pi_i b_i(o_1) \quad \text{for } 1 \le i \le N$$
Recursion:
$$\alpha_t(j) = \left[ \sum_{i=1}^N \alpha_{t-1}(i) a_{ij} \right] b_j(o_t) \quad \text{for } 1 < t \le T, 1 \le j \le N$$
Termination:
$$P(O | \lambda) = \sum_{i=1}^N \alpha_T(i)$$
This dynamic programming approach avoids exponential complexity by reusing intermediate calculations.

### Viterbi Algorithm for Decoding

The Viterbi algorithm efficiently finds the single most probable sequence of hidden states $Q^* = (q_1^*, q_2^*, ..., q_T^*)$ given an observation sequence $O$ and an HMM $\lambda$. It uses dynamic programming to track the maximum probability path to each state at each time step.

Let $\delta_t(i)$ be the maximum probability of any path ending in state $s_i$ at time $t$ and generating the partial observation sequence $O_t$.

Initialization:
$$\delta_1(i) = \pi_i b_i(o_1) \quad \text{for } 1 \le i \le N$$
Recursion:
$$\delta_t(j) = \max_{1 \le i \le N} [\delta_{t-1}(i) a_{ij}] b_j(o_t) \quad \text{for } 1 < t \le T, 1 \le j \le N$$
A backtracking pointer $\psi_t(j)$ is stored to reconstruct the path.

Termination:
$$P^* = \max_{1 \le i \le N} [\delta_T(i)]$$
The optimal path is found by backtracking from $q_T^* = \arg\max_{1 \le i \le N} [\delta_T(i)]$ using the $\psi$ pointers.

## Algorithm Steps

1. Initialize the HMM parameters $\lambda = (A, B, \pi)$ randomly or using a heuristic, ensuring that all probabilities sum to one.
2. Perform the E-step (Expectation): For each observation sequence $O$, compute the expected number of transitions and emissions using the Forward and Backward algorithms to derive $\gamma_t(i) = P(q_t = s_i | O, \lambda)$ and $\xi_t(i, j) = P(q_t = s_i, q_{t+1} = s_j | O, \lambda)$.
3. Perform the M-step (Maximization): Re-estimate the HMM parameters $\lambda' = (A', B', \pi')$ using the expected counts from the E-step, where $\pi'_i = \gamma_1(i)$, $a'_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i, j)}{\sum_{t=1}^{T-1} \gamma_t(i)}$, and $b'_j(k) = \frac{\sum_{t=1, o_t=v_k}^{T} \gamma_t(j)}{\sum_{t=1}^{T} \gamma_t(j)}$.
4. Check for convergence: If the log-likelihood $P(O | \lambda)$ has converged (i.e., the change in log-likelihood is below a specified tolerance) or a maximum number of iterations is reached, stop.
5. Otherwise, set $\lambda = \lambda'$ and repeat from step 2.

## Strengths

- HMMs provide a robust probabilistic framework for modeling sequential data with underlying latent states.
- The Forward-Backward algorithm allows for efficient computation of the likelihood of an observation sequence.
- The Viterbi algorithm efficiently finds the most probable sequence of hidden states, which is crucial for decoding tasks.
- The Baum-Welch algorithm provides an effective method for learning model parameters from unlabeled observation sequences.
- HMMs are interpretable, as the learned states can often correspond to meaningful physical or linguistic phenomena.
- They are versatile and have been successfully applied across diverse domains, including speech, bioinformatics, and finance.

## Weaknesses

- The fundamental assumption of a first-order Markov process for state transitions can be overly simplistic for complex real-world sequences.
- HMMs struggle with long-range dependencies in sequences, as the current state only depends on the previous one.
- The number of hidden states must be chosen a priori, and an incorrect choice can significantly impact model performance.
- The Baum-Welch algorithm is susceptible to local optima, meaning the learned parameters might not be globally optimal.
- HMMs assume conditional independence of observations given the current state, which may not hold true in all applications.

## Use Cases

### Speech Recognition

Used to model phonemes or sub-phonetic units, where the observed data are acoustic features and the hidden states are the spoken words or sounds.

### Bioinformatics

Applied for gene finding, protein secondary structure prediction, and sequence alignment, treating DNA/protein sequences as observations and functional regions as hidden states.

### Natural Language Processing

Employed in part-of-speech tagging, named entity recognition, and machine translation, where words are observations and grammatical categories or entities are hidden states.

### Financial Modeling

Used for analyzing market regimes, predicting stock price movements, or detecting anomalies in financial time series, with market conditions as hidden states.

### Gesture Recognition

Applied to interpret sequences of sensor data (e.g., accelerometer readings) as specific gestures, where gestures are the hidden states.
