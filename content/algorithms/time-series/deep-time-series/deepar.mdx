## Overview

[DeepAR](/algorithms/time-series/deepar) is a deep learning-based probabilistic forecasting model designed for time series data. It leverages recurrent neural networks (RNNs), specifically LSTMs or GRUs, to learn global patterns across a large collection of related time series. By modeling the conditional distribution of future values given past observations and covariates, DeepAR provides full probabilistic forecasts, including prediction intervals, rather than just point estimates.

## History

**2017** — Amazon researchers, including David Salinas, Valentin Flunkert, and Jan Gasthaus, introduced DeepAR in their seminal paper 'DeepAR: Probabilistic Forecasting with Autoregressive Recurrent Networks'. This marked a significant advancement in applying deep learning to probabilistic time series forecasting at scale.

**2019** — DeepAR was integrated into Amazon Forecast, a fully managed service that uses machine learning to generate highly accurate forecasts, making the algorithm widely accessible for business applications.

**2020** — Further research and open-source implementations, such as those within the GluonTS library, expanded the accessibility and adaptability of DeepAR, allowing practitioners to experiment with and deploy the model in various environments.

## Mathematical Intuition

### Probabilistic Forecasting Framework

DeepAR aims to model the conditional distribution of future target values $z_{t_0:T}$ given past observations $z_{1:t_0-1}$ and optional covariates $x_{1:T}$. This is expressed as $P(z_{t_0:T} | z_{1:t_0-1}, x_{1:T})$. The model decomposes this joint distribution into a product of conditional distributions for each time step, assuming an autoregressive structure: $$P(z_{t_0:T} | z_{1:t_0-1}, x_{1:T}) = \prod_{t=t_0}^T P(z_t | z_{1:t-1}, x_{1:T})$$ The core idea is that an RNN learns to parameterize $P(z_t | z_{1:t-1}, x_{1:T})$ at each time step.

### Recurrent Neural Network Core

At the heart of DeepAR is a [Recurrent Neural Network](/algorithms/deep-learning/recurrent-neural-network) (RNN), typically an [LSTM](/algorithms/deep-learning/lstm) or [GRU](/algorithms/deep-learning/gru). The RNN processes the time series sequentially, maintaining a hidden state $h_t$ that encapsulates information from past observations and covariates. At each time step $t$, the RNN takes the previous hidden state $h_{t-1}$, the current target value $z_{t-1}$ (or a sampled value during prediction), and current covariates $x_t$ as input to compute the new hidden state $h_t$: $$h_t = f(h_{t-1}, z_{t-1}, x_t; \theta_{RNN})$$ where $f$ is the RNN cell function and $\theta_{RNN}$ are its parameters. This hidden state $h_t$ then informs the parameters of the output distribution.

### Output Distribution Parameterization

The RNN's output at time $t$, derived from $h_t$, is used to parameterize a chosen likelihood distribution $P(z_t | \theta_t)$. Common choices for this distribution include Gaussian, Negative Binomial, or Student's t-distribution, depending on the nature of the target variable (e.g., continuous, count data). For a Gaussian distribution, the RNN output would predict the mean $\mu_t$ and standard deviation $\sigma_t$ at time $t$: $$\mu_t, \sigma_t = g(h_t; \theta_{output})$$ where $g$ is a neural network layer (e.g., a dense layer) that maps the hidden state to the distribution parameters. The likelihood function for a single observation $z_t$ is then $P(z_t | \mu_t, \sigma_t)$.

### Training and Sampling for Forecasts

The model is trained by maximizing the log-likelihood of the observed training data. The objective function is to minimize the negative log-likelihood: $$L(\theta) = -\sum_{i=1}^N \sum_{t=1}^{T_i} \log P(z_{i,t} | z_{i,1:t-1}, x_{i,1:T_i}; \theta)$$ where $N$ is the number of time series, $T_i$ is the length of series $i$, and $\theta$ represents all model parameters. During prediction, future values are generated by iteratively sampling from the predicted distribution. For each future time step $t$, a value $z_t$ is sampled from $P(z_t | z_{1:t-1}, x_{1:T})$, and this sampled value is then fed back into the RNN as input for the next time step $t+1$. This autoregressive sampling process allows for the generation of multiple plausible future trajectories, providing a full probabilistic forecast.

## Algorithm Steps

1. Prepare the time series data, including any static or dynamic covariates, ensuring consistent formatting across all series.
2. Define the recurrent neural network architecture (e.g., LSTM or GRU) and its hyperparameters, such as the number of layers and hidden units.
3. Select an appropriate likelihood distribution (e.g., Gaussian, Negative Binomial) based on the characteristics of the target variable.
4. Initialize the model parameters randomly and define an optimizer (e.g., [Adam](/algorithms/meta-learning/adam)) and a learning rate.
5. Train the model by iteratively feeding batches of historical time series data through the RNN, computing the negative log-likelihood loss, and updating parameters via backpropagation.
6. During training, the RNN learns to map past observations $z_{1:t-1}$ and covariates $x_{1:T}$ to the parameters of the likelihood distribution $P(z_t | \theta_t)$ for each time step $t$.
7. To generate forecasts, provide the model with the historical context window and covariates for the prediction horizon.
8. Iteratively sample a value $z_t$ from the predicted distribution $P(z_t | z_{1:t-1}, x_{1:T})$ for the current future time step, then feed this sampled value back into the RNN as input for the next time step, repeating until the full prediction horizon is covered.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `num_layers` | `integer` | `2` | 1 to 5 | Number of recurrent layers in the RNN. |
| `hidden_size` | `integer` | `40` | 10 to 200 | Number of units in the hidden state of each recurrent layer. |

| `prediction_length` | `integer` | `10` | 1 to 100 | The number of future time steps to forecast. |
| `epochs` | `integer` | `100` | 10 to 1000 | The number of training epochs. |
| `learning_rate` | `float` | `0.001` | 0.0001 to 0.1 | The learning rate for the optimizer. |
| `batch_size` | `integer` | `32` | 1 to 256 | The number of time series samples processed in each training iteration. |

## Strengths

- DeepAR provides full probabilistic forecasts, offering prediction intervals and quantiles, which is crucial for decision-making under uncertainty.
- It can learn global patterns across a large collection of related time series, leading to improved accuracy, especially for series with limited individual history.
- The model naturally handles missing values and irregular time series by design, as the RNN can process sequences with varying lengths.
- DeepAR can incorporate various static and dynamic covariates, allowing for richer contextual information to influence forecasts.
- Its deep learning architecture can capture complex non-linear temporal dependencies that simpler models might miss.
- The model is scalable to large datasets with many time series, making it suitable for enterprise-level forecasting applications.

## Weaknesses

- DeepAR requires a substantial amount of historical data and a large collection of related time series to effectively learn global patterns.
- Training DeepAR models can be computationally intensive and time-consuming, especially for complex architectures or very long time series.
- The model's performance is highly sensitive to hyperparameter tuning, which can be a challenging and iterative process.
- DeepAR, like many deep learning models, can be less interpretable than traditional statistical methods, making it difficult to understand the drivers of specific forecasts.
- It may struggle with highly volatile or extremely sparse time series where insufficient patterns can be learned.
