## Overview

The [Temporal Fusion Transformer](/algorithms/time-series/temporal-fusion-transformer) (TFT) is a novel deep learning architecture designed for high-performance multi-horizon time series forecasting. It leverages self-attention mechanisms and specialized gating layers to achieve state-of-the-art accuracy while providing interpretable insights into temporal dynamics and feature importance. TFT effectively handles both static and time-varying exogenous inputs, distinguishing between known future inputs and unknown future inputs.

## History

**2017** — Vaswani et al. introduce the [Transformer](/algorithms/deep-learning/transformer) architecture, revolutionizing sequence modeling with self-attention. This foundational work laid the groundwork for subsequent Transformer-based models in various domains.

**2020** — Bryan Lim, Sercan Ö. Arik, Nicolas Loeff, and Tomas Pfister publish "Temporal Fusion Transformers for Interpretable Multi-horizon Time Series Forecasting". This paper introduces the TFT, specifically adapting the Transformer architecture for time series data and emphasizing interpretability.

**2020** — Following its introduction, TFT gains significant traction in research and industry due to its strong performance and interpretability features, leading to its adoption in various forecasting applications and inspiring further research into Transformer-based time series models.

## Mathematical Intuition

### Gated Linear Units (GLU)

TFT employs Gated Linear Units to control the flow of information through the network, enhancing non-linearity and allowing the model to selectively propagate relevant features. This mechanism helps in filtering out irrelevant information by element-wise multiplication with a sigmoid-activated gate.

$$
\text{GLU}(x) = (W_1x + b_1) \odot \sigma(W_2x + b_2)
$$

### Multi-Head Self-Attention

The core temporal processing in TFT uses a multi-head self-[Attention Mechanism](/algorithms/deep-learning/attention-mechanism) to capture long-range dependencies and complex temporal patterns. This allows the model to weigh the importance of different time steps in the input sequence when making a prediction. Multi-head attention applies the scaled dot-product Attention Mechanism multiple times in parallel with different linear projections of query ($Q$), key ($K$), and value ($V$) matrices, then concatenates and linearly transforms the outputs.

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

### Variable Selection Networks

To enhance interpretability and focus on important features, TFT incorporates Variable Selection Networks at both the static and temporal levels. These networks learn a set of weights for each input feature, effectively determining its relevance. The input features $x_i$ are passed through a Multi-Layer [Perceptron](/algorithms/supervised/perceptron) (MLP) to generate scores, which are then normalized by a softmax function to produce attention-like weights. These weights are used to scale the input features, allowing the model to prioritize more informative variables.

$$
\text{Weights}_i = \text{softmax}(\text{MLP}(x_i))
$$

### Static Covariate Encoders

TFT processes static (time-invariant) covariates through dedicated encoders to enrich the representation of each time series. These encoders generate a context vector that is then used to condition the temporal processing. The static context vector $c$ is typically generated by passing the static covariates through a series of dense layers. This context is then integrated into the Variable Selection Networks and the Gated Residual Connections, allowing the model to adapt its behavior based on the inherent characteristics of each series.

$$
c = \text{Encoder}(\text{static\_covariates})
$$

## Algorithm Steps

1. Embed all static and time-varying input features into a common latent space using dedicated embedding layers.
2. Process static covariates through a Static Covariate Encoder to generate a static context vector, which conditions subsequent processing.
3. Apply Variable Selection Networks to both static and time-varying inputs, learning weights to determine the importance of each feature.
4. Pass the selected time-varying features through a Gated Residual Network, which incorporates Gated Linear Units for non-linear processing and information flow control.
5. Apply a Multi-Head Self-Attention mechanism to the processed time-varying inputs to capture long-range temporal dependencies.
6. Integrate the static context vector and the output of the attention mechanism through further Gated Residual Networks.
7. Generate multi-horizon forecasts by passing the final processed representation through a decoder network, typically a feed-forward layer, to predict quantiles or point estimates for each future time step.

## Parameters

| Parameter | Type | Default | Range / Options | Description |
|---|---|---|---|---|
| `hidden_size` | `integer` | `160` | positive integer | The dimensionality of the internal representations and embeddings. |
| `num_heads` | `integer` | `4` | positive integer | Number of parallel attention layers, allowing the model to jointly attend to information from different representation subspaces. |

## Strengths

- Provides state-of-the-art forecasting accuracy across various complex multi-horizon time series datasets.
- Offers high interpretability through Variable Selection Networks and attention mechanisms, revealing feature importance and temporal dependencies.
- Effectively handles both static and time-varying exogenous inputs, including known future inputs and unknown future inputs.
- Can model complex non-linear relationships and long-range dependencies in time series data due to its transformer-based architecture.
- Supports multi-horizon forecasting, predicting multiple future time steps simultaneously.
- Robust to missing values and noisy data through its robust embedding and gating mechanisms.

## Weaknesses

- Requires a substantial amount of data for effective training, especially compared to simpler statistical or machine learning models.
- High computational cost and memory footprint during training and inference, particularly for long input sequences or large models.
- Complex architecture can be challenging to implement and fine-tune without specialized deep learning frameworks.
- Interpretability features, while present, can still be challenging to fully leverage for non-experts.
- Performance can degrade if the underlying data distribution changes significantly over time (concept drift) without retraining.
