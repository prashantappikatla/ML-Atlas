## Overview

Adaptive Neuro-[Fuzzy Inference System](/algorithms/evolutionary/fuzzy-systems/fuzzy-inference-system) (ANFIS) is a hybrid intelligent system that combines the learning capabilities of artificial neural networks with the human-like reasoning of fuzzy inference systems. It constructs a Sugeno-type [Fuzzy Inference System](/algorithms/evolutionary/fuzzy-systems/fuzzy-inference-system) whose parameters are tuned using a neural network learning algorithm. This architecture allows ANFIS to approximate nonlinear functions and model complex systems by learning from data, offering both adaptability and interpretability.

## History

**1993** — Jyh-Shing Roger Jang introduced the Adaptive Neuro-[Fuzzy Inference System](/algorithms/evolutionary/fuzzy-systems/fuzzy-inference-system) (ANFIS), proposing a novel architecture that integrates neural networks and fuzzy logic for adaptive learning.

**1993** — Jang's seminal paper "ANFIS: Adaptive-Network-based [Fuzzy Inference System](/algorithms/evolutionary/fuzzy-systems/fuzzy-inference-system)" laid the theoretical foundation and demonstrated its capabilities for function approximation and system identification.

**1995** — Research expanded on ANFIS applications in control systems, pattern recognition, and prediction tasks, leveraging its ability to learn from data while maintaining interpretability.

**2001** — Further developments focused on optimizing ANFIS training algorithms, exploring different membership functions, and extending its applicability to more complex, high-dimensional problems.

## Mathematical Intuition

### ANFIS Architecture Overview

ANFIS integrates a Sugeno-type [Fuzzy Inference System](/algorithms/evolutionary/fuzzy-systems/fuzzy-inference-system) into a five-layer feedforward neural network structure. Each layer performs a specific function, transforming inputs through fuzzy membership functions, fuzzy rules, and defuzzification to produce an output. The adaptive parameters within this network, such as membership function parameters and consequent parameters, are optimized during the learning phase.

$$
\text{Layer 1: Fuzzification}
$$

$$
\text{Layer 2: Rule Premise}
$$

$$
\text{Layer 3: Normalization}
$$

$$
\text{Layer 4: Consequent Calculation}
$$

$$
\text{Layer 5: Defuzzification}
$$

### Sugeno-Type Fuzzy Inference

ANFIS employs a first-order Sugeno fuzzy model, where each rule's output is a linear combination of the input variables plus a constant term. For a two-input, one-output system, a typical Sugeno rule might be: IF $x$ is $A_i$ AND $y$ is $B_i$, THEN $f_i = p_i x + q_i y + r_i$. Here, $A_i$ and $B_i$ are fuzzy sets, and $p_i, q_i, r_i$ are consequent parameters. The final output is a weighted average of the individual rule outputs, where $w_i$ is the firing strength of rule $i$, and $\bar{w}_i$ is the normalized firing strength.

$$
O = \sum_{i=1}^N \bar{w}_i f_i = \frac{\sum_{i=1}^N w_i f_i}{\sum_{i=1}^N w_i}
$$

### Hybrid Learning Algorithm

ANFIS utilizes a hybrid learning algorithm that combines gradient descent with the least squares method to efficiently update its parameters. In the forward pass, the network outputs are calculated, and the consequent parameters ($p_i, q_i, r_i$) are identified using the least squares method. In the backward pass, the premise parameters (parameters of the membership functions) are updated using gradient descent to minimize the error $E$. The update rule for a premise parameter $\alpha$ involves its partial derivative with respect to the error.

$$
E = \frac{1}{2} \sum_{k=1}^P (T_k - O_k)^2
$$

$$
\alpha_{t+1} = \alpha_t - \eta \frac{\partial E}{\partial \alpha}
$$

## Algorithm Steps

1. Initialize the ANFIS structure by defining the number of fuzzy rules, the type and initial parameters of membership functions (e.g., Gaussian, triangular), and the consequent parameters.
2. Perform a forward pass through the network, where input data is fuzzified using membership functions, and firing strengths $w_i$ for each rule are calculated.
3. Normalize the firing strengths for each rule by dividing by the sum of all firing strengths to obtain $\bar{w}_i$.
4. Calculate the output of each Sugeno rule $f_i = p_i x + q_i y + r_i$ as a linear combination of inputs and consequent parameters.
5. Compute the overall ANFIS output $O = \sum \bar{w}_i f_i$ as a weighted average of the individual rule outputs.
6. In the forward pass, use the least squares method to identify the optimal consequent parameters ($p_i, q_i, r_i$) that minimize the error between the ANFIS output and the target output.
7. In the backward pass, propagate the error backward through the network, and use gradient descent to update the premise parameters (membership function parameters) to further reduce the error.
8. Repeat steps 2-7 for a specified number of epochs or until a convergence criterion is met.

## Strengths

- ANFIS can approximate complex nonlinear functions with high accuracy due to its adaptive learning capabilities.
- It combines the interpretability of fuzzy logic with the learning power of neural networks, offering insights into the learned rules.
- The hybrid learning algorithm efficiently optimizes both premise and consequent parameters, leading to faster convergence compared to pure gradient-based methods.
- ANFIS is robust to noisy data and can generalize well to unseen data if properly trained.
- It provides a transparent model structure where the fuzzy rules can be extracted and understood.
- The model can be incrementally updated with new data, allowing for online learning in dynamic environments.

## Weaknesses

- The number of fuzzy rules and parameters grows exponentially with the number of input variables, leading to the curse of dimensionality for high-dimensional data.
- ANFIS can be computationally intensive and slow to train for large datasets or systems with many inputs.
- The initial choice of membership function types and their parameters can significantly impact the model's performance and convergence.
- It is prone to overfitting if the number of rules is too high or the training data is insufficient.
- ANFIS typically requires numerical inputs and outputs, making it less suitable for categorical data without prior encoding.

## Use Cases

Predicting stock prices, exchange rates, or market trends based on historical financial data and economic indicators.

### Medical Diagnosis

Assisting in the diagnosis of diseases by modeling relationships between patient symptoms, test results, and medical conditions.

### Environmental Modeling

Forecasting weather patterns, air quality, water levels, or pollution dispersion based on various environmental factors and sensor data.

### System Identification

Building mathematical models of unknown or partially known systems from observed input-output data for analysis and prediction.

### Pattern Recognition

Classifying patterns in data, such as speech recognition, handwriting recognition, or image classification after appropriate feature extraction.
